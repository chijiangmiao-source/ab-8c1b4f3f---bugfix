# 闪烁探测器脉冲堆积 · 离线解卷积审计页

高计数率下相邻光子脉冲叠成一条波形，逐峰扣除会把早期误差传播到整段记录。
本工具在**纯浏览器本地**对整段记录做一次性离线解卷积，给出可重算、可复核的证据：
规范解、逐点残差，以及每个位置在全部全局同优解中可取的精确计数集合。

- 不创建业务后端，不调用任何在线服务；页面为静态文件，所有计算在浏览器内完成。
- 静态 Web 由 `Dockerfile` 构建、`docker compose` 发布，宿主机端口可配置。
- `docker-compose.yml` 中名为 `verify` 的一次性服务自行退出，用退出码报告
  代码测试、构建检查与 HTTP 冒烟结果。

## 数学模型与判定规则

- 观测波形 `y`：长度 `m ∈ [12, 300]`，非负整数。
- 响应核 `h`：长度 `k ∈ [2, 7]`，非负整数，且首项、末项必须为正。
- 潜在脉冲序列 `x`：长度 `n = m − k + 1`，每个位置 `0 ≤ x[j] ≤ u[j]`，`u[j] ∈ [0, 4]`。
- 重建为长度 `m` 的离散卷积 `(x*h)[t] = Σ_i h[i]·x[t−i]`，**越界项按零卷积**。

目标按字典序分层：

1. 最小化绝对残差总和 `L1 = Σ_t |y[t] − (x*h)[t]|`；
2. 在第一层最优解中最小化脉冲总数 `Σ_j x[j]`；
3. 在前两层最优解中取脉冲向量字典序最小者作为**规范解**。

页面同时给出每个位置 `j` 在满足①②的**全部全局同优解**中 `x[j]` 可取的精确计数集合；
集合含多个值的位置即"存在同优计数的位置"，在图与表中标出。

### 算法

残差 `r_t` 只依赖最近 `k−1` 个脉冲值，以此为状态做动态规划（状态数 ≤ 5^6 = 15625）：

- 反向递推每个状态到结尾的最优代价 `B`（含尾部 `t = n..m−1` 的零边界残差）；
- 正向递推到每个状态的最优前缀代价 `F`；
- 位置 `j` 取值 `v` 出现在某全局同优解 ⟺ 存在状态使 `F + 步代价 + B == 全局最优`
  （按 `(L1, 脉冲数)` 字典序比较），据此得到精确的计数集合；
- 规范解在保持该等式的前提下逐位取最小 `v`。

最坏规模（m=300, k=7, u≡4）求解约 0.3 s。所有量为整数，输入取值限制在 `0..1e9`
以内，保证 L1 总和远低于 2^53，浮点整数运算精确无舍入。

## 运行（Docker）

```bash
# 构建并后台启动 Web（宿主机端口默认 8080，可用 WEB_PORT 配置）
WEB_PORT=8080 docker compose up --build -d web

# 访问 http://localhost:8080 ；健康检查端点 http://localhost:8080/health

# 运行一次性核验服务：代码测试 + 构建检查 + 对 web 的 HTTP 冒烟
# 该服务执行完自行退出，退出码即核验结果（0 通过 / 非 0 失败）
docker compose run --build --rm verify
echo "verify exit: $?"

# 或者：docker compose up --build --exit-code-from verify verify

docker compose down
```

`verify` 核对的内容包括：卷积边界（越界项按零卷积）、双层最优规则
（先 L1 后脉冲总数、字典序规范解）、存在同优计数的位置
（计数集合与暴力枚举随机对拍），以及 `/health`、首页与打包资源的 HTTP 冒烟。

## 本地开发

```bash
npm install
npm run dev       # 开发服务器
npm run test:ci   # 单元测试（含暴力枚举对拍）
npm run build     # 类型检查 + 静态构建到 dist/
```

## 输入格式

- 三个输入框均以逗号/空白/中文逗号分隔非负整数；非法输入**保留原文**，
  错误按字段与序号定位原因，页面继续展示最近一次合法输入的解。
- 脉冲上限 `u`：单个值广播到全部 `n` 个位置，或给出与 `n = m − k + 1` 等长的序列。

## 目录结构

```
src/solver.ts     解卷积求解器（分层目标 DP + 同优计数集合）
src/parse.ts      输入解析与校验（错误定位）
src/charts.tsx    联动 SVG 图表（观测/重建、残差、脉冲与同优集合）
src/App.tsx       审计页
tests/            单元测试与暴力枚举对拍
scripts/verify.mjs 一次性核验服务入口
Dockerfile        多阶段：deps → build → web(nginx) / verify
docker-compose.yml web（端口 ${WEB_PORT:-8080}）+ verify（一次性）
nginx.conf        静态服务 + /health 健康检查
```
